## 这个系列是关于什么的？

设计模式的教程不少，但大多停留在教科书式的定义上，看完还是不知道该在什么时候用。这个系列换一种讲法：

- 每种模式先用**生活中的例子**解释清楚它到底在解决什么问题；
- 再给出一段不用该模式的**"烂代码"场景**，让你体会痛点在哪；
- 然后用**完整可运行的 Java 代码**做实战演练；
- 最后实事求是地分析**优缺点与适用场景**——什么时候该用，什么时候别用。

文章讲原理，[演示站](https://yeatsliao.github.io/design-patterns-23/) 管交互：每种模式在网站上都有一个用 React 实现的动态演示（比如模拟工厂生产产品、观察者收到通知），两边配合着看效果最好。

## 适合谁读

- 学过 Java 语法、想进阶面向对象设计的开发者
- 背过模式定义、但一写代码就不知道怎么落地的读者
- 准备面试、需要快速过一遍 23 种模式的求职者
