# 小米米家 · 稳定连接：配网激活与弱网自适应

> 技术栈：米家 App 配网（扫码 / 蓝牙辅助）+ 一机一密 + 局域网 / 云端双通道（以小米米家 / MiOT 为案例）
> 适用场景：无屏设备如何自助配网、弱网如何保活

工业设备由工程师烧录配置、插上网线就能跑。米家设备却要让一个不懂 DNS 的用户，把 Wi-Fi 密码交给一个没有屏幕的灯泡。

配网之所以难，是因为它发生在「设备还没有身份、没有密钥、没有网络」的真空状态。米家要在这个状态下，把 SSID 与密码安全送进去，给设备建立一机一密的长期身份——还不能让用户学任何网络知识。

这一篇按「进得来（配网）→ 控得稳（双通道）→ 待得住（保活）→ 活得久（低功耗）」的顺序拆开看。

## 1.问题背景：米家配网难与弱网下的真实痛点

- **设备没有输入界面**：灯泡、插座连一个按键都吝啬，更别说屏幕键盘。米家靠扫码配网、蓝牙辅助配网把这件事简化到「开 App 扫一下」。
- **家庭 Wi-Fi 环境恶劣**：2.4G/5G 双频混淆、信道拥挤、墙体遮挡。运营商路由器常开启「双频合一」，而多数 IoT 设备只支持 2.4G，配网极易连错频段。
- **用户容忍度极低**：工业配网失败可以派工程师，米家配网失败用户只会差评退货。一次失败就可能让整盒设备吃灰。
- **密钥不能明文飞**：密码经手机发给设备，途中若被嗅探，等于把全家网络拱手让人。米家强调一机一密与证书链，密钥不下落明文。
- **电池设备要省电**：门锁、门窗传感器靠电池供电，一枚纽扣电池要撑一年以上。若为「实时在线」保持长连，续航从一年缩到一周。

## 2.设计理念：为什么把配网、双通道、保活分开设计

配网、连接通道、保活其实是三件事，米家把它们拆开各自优化：

### 2.1 配网：一次性送身份与密钥

米家 App 根据设备能力选择扫码配网、蓝牙辅助配网（BLE 先把 Wi-Fi 凭证传给设备，最稳最友好）、或一键快连。目标是零输入，且密钥不下落明文。

```text
蓝牙辅助配网流程（代表性，非真实 SDK）：
1. 设备进入配网态，广播 BLE 广播包
2. 米家 App 发现设备并建立 BLE 连接
3. App 写入加密的 SSID / 密码 + 账号 token
4. 设备断开 BLE，自行连接路由器
5. 设备连云激活，向 App 回报成功
```

### 2.2 一机一密：身份锚点

每台设备出厂烧录唯一密钥/证书链，云端按设备身份（did + Product ID + MAC）鉴权，而非按型号。一台被攻破不会连累一片。

### 2.3 双通道：本地快、远程达

| 通道 | 场景 | 特点 |
|------|------|------|
| 局域网协议 | 同网段操控与联动 | 低延迟（百毫秒内）、断网仍可用 |
| 小米云（MQTT/HTTPS） | 远程控制与多端同步 | 跨地域可达、云端转发 |

App 自动择优：检测到同网段设备走本地，否则回退云端。

### 2.4 保活与低功耗

长连 + 心跳探活，断线后指数退避重连（1s→2s→4s…上限封顶）配合随机抖动，防雪崩。电池设备深度休眠，仅在需要时建连：

- **门窗传感器**：事件触发，开门瞬间唤醒
- **温湿度传感器**：RTC 定时唤醒，兼顾时效与续航
- **BLE Mesh 低功耗节点**：好友节点代收消息，平均电流微安级

## 3.实际应用：米家 App 配网激活与弱网自适应

### 3.1 多模式配网并存

米家 App 根据设备能力选择配网模式。带 BLE 的双模设备优先走蓝牙辅助，成功率最高。整个过程用户只需「靠近、点确认」，无需输入任何字符。

### 3.2 一机一密激活

设备首次连云时，用出厂烧录的唯一证书链做双向认证。小米云为其建立长期身份与设备影子（见第四篇），此后每次连接都按此身份鉴权。

### 3.3 双通道协同

同局域网内走米家局域网协议做本地操控（断网可用）。远程与多端同步走小米云 MQTT/HTTPS 实现跨地域控制。用户在客厅关灯走本地通道延迟百毫秒内，人在公司看家里摄像头走云端隧道。

### 3.4 长连保活与重连

网络抖动时本地缓存关键状态，恢复后补报。路由器改密后设备重连失败，会重新进入配网态或走蓝牙辅助回连，避免永久失联。

## 4.注意事项

- **配网失败要给「可救」的反馈**：区分「设备没进配网态」「Wi-Fi 密码错」「路由器 5G 不支持」，给出对应引导。配网失败率应作为新品验收的核心指标。
- **一机一密要配套转让流程**：设备转卖时云端应吊销 token 并清除家庭绑定，转让家庭时一并迁移场景与权限。
- **心跳与离线判定要权衡**：云端判定离线阈值不应比设备实际重连时间还短，否则频繁误报。本地联动是体验底线，远程控制是增值能力。

## 5.小结

米家消费级连接的第一性原理是「让人无感地把设备接进来，并让它在糟糕的家庭网络里又稳又省」：

| 维度 | 工业/通用 IoT | 米家/MiOT 消费级 |
|------|-------------|---------------|
| 配网 | 工程师烧录 | 用户自助：扫码 / 蓝牙辅助 |
| 身份 | 按型号/网关 | 一机一密、did+PID+MAC |
| 通道 | 单一长连 | 局域网 + 云端双通道 |
| 保活 | 专线冗余 | 心跳 + 指数退避防雪崩 |
| 功耗 | 常电为主 | 电池设备深度休眠 |
